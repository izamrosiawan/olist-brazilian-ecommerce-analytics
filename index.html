05. METODOLOGI SQL

Kueri Produksi Data Warehouse

Kueri SQL dengan Window Functions yang digunakan untuk memproses agregasi data 100.000 transaksi. 

-- 1. Evaluasi Disparitas Pengiriman per Wilayah
SELECT 
    c.customer_state,
    COUNT(o.order_id) AS total_orders,
    ROUND(AVG(julianday(o.order_delivered_customer_date) - julianday(o.order_purchase_timestamp)), 1) AS avg_delivery_days,
    ROUND(AVG(r.review_score), 2) AS avg_review_score
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
JOIN order_reviews r ON o.order_id = r.order_id
WHERE o.order_status = 'delivered'
GROUP BY c.customer_state
ORDER BY total_orders DESC;
